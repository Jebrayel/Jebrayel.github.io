The platform that runs Cedaris

Cedaris is the PVC fencing supply and installation company I co-own in Ottawa. We were managing quotes, invoices, inventory, suppliers and the books across five different apps, so I designed and shipped one platform to replace them.

  • Inventory, quoting, invoicing with PDF and email delivery, a CRM pipeline, a customer portal and double-entry bookkeeping with HST.
  • Money is stored in integer cents. The ledger rejects any entry where debits and credits differ, and an invoice posts in a single database transaction.
  • 235 automated tests across 49 suites, including a simulated month of trading that proves the books balance.
  • Deployed on Railway with managed PostgreSQL and gated migrations through GitHub CI/CD. One codebase serves the public site and the back office.

How it was built. I used Claude Code for implementation and owned the requirements, architecture, code review, testing and deployment. I am now working through the stack by hand so I can write every part of it myself.

  • React 19
  • TypeScript

  • PostgreSQL
  • Tailwind CSS
